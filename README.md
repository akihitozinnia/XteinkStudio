# Xteink Studio

文書や画像を、Xteink向けのXTCに変換するWindowsアプリです。

## ダウンロード
右側の「Releases」からWindows版ZIPをダウンロードしてください。

## 主な機能
- EPUB・Word・PDF・画像・CBZなどからXTCへ変換
- 縦書き・ルビ、Noto明朝／ゴシックに対応
- 文字サイズ・太さ・行間・余白の調整
- 実機サイズのプレビュー（表示寸法の調整が必要）
- フォルダ読み込み、ページの並べ替え・削除

## 使い方
1. ZIPをすべて展開
2. XteinkStudio.exeを起動
3. ファイルを選択し、設定を確認して読み込み
4. XTCを作成して保存

EXEと_internalフォルダは一緒に置いてください。
Pythonのインストールは不要です。
Microsoft Edge WebView2 Runtimeが必要です。

## 動作確認
- Windows 11 64ビットで確認
- X3：従来の出力を実機確認済み
- X4：出力対応・実機未確認

## 同梱ソフトウェア
Notoフォントなどのライセンス文書は配布ZIP内に同梱しています。
